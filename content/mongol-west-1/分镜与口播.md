## 一、视觉总案

**母题：案卷 / 证物板。** 整支片像在翻一份 13 世纪的战争卷宗：羊皮纸底、墨色地形、朱红蜡封、铜色编号。地图是桌面，档案卡是证物，时间轴是卷宗侧边的索引标签。

- **地图**：从蒙古高原到里海的竖幅示意地图；只画海岸线、主要河流和城市节点，不画现代国界。常驻角标“地图为示意，非精确古地理”。
- **时间轴**：画面左侧纵向窄条，1218 / 1219 / 1220 三个年份；红色进度线随旁白推进，事件用小字挂在轴上。
- **档案卡**：底部上滑的证物卡，每张只放一句史料摘句、书名、页码和一枚“史料有异 / 一说”的印章。不做大段引用。
- **色彩**：墨 #171512、羊皮纸 #E8DCC3、朱红 #A63A2B、铜 #A98245、河湖青 #4E6E68。
- **字体**：标题用宋体 / 思源宋体，数字用等宽；字幕用思源黑体。字体文件待确认授权，发布前按 `docs/资产来源与许可.md` 核对。
- **动效**：全部用 paused GSAP timeline，可 seek；不做依赖实时时钟的循环。印章用缩放 + 透明度，路线用 `stroke-dashoffset`，城市陷落用红色印章覆盖，银液用 SVG mask / CSS 渐变。

## 四、地图设计

- **范围**：约 30°E–110°E、30°N–55°N；竖幅裁切，左下里海，右上蒙古高原。
- **底图**：Natural Earth 公版数据（海岸线、湖泊、主要河流）或手绘 SVG；不画现代国界，不标现代城市。
- **节点**：讹答剌（约 42.85°N, 68.30°E）、布哈拉（约 39.77°N, 64.42°E）、撒马尔罕（约 39.65°N, 66.96°E）、里海中的示意小岛。点位为近似值，画面标“示意”。
- **路线**：蒙古高原 → 天山北路 → 锡尔河 → 讹答剌 → 布哈拉 / 撒马尔罕 → 里海。路线为叙事性连线，不是可量测的行军复原。
- **城市陷落**：不用火焰 / 爆炸，用红色印章覆盖城市节点；与“案卷”母题一致。
- **时间轴**：左侧纵向，1218 / 1219 / 1220；事件标签只挂“商队 / 西征 / 围城 / 布哈拉 / 撒马尔罕 / 里海”。不做精确比例尺。

## 五、旁白与字幕

- 口播稿：`content/mongol-west-1/口播稿.txt`，8 段，289 个汉字（不含标点）。
- 按 dabao 6.2 字/秒上限，纯语音约 47–50 s；留 10–13 s 给画面停顿、印章和收束卡。实际时长以 TTS 输出为准。
- 专名读音：见 `事实底稿.md` 第三节。**先做 20–30 秒试听**，确认“讹答剌 / 亦纳勒术 / 花剌子模 / 摩诃末”四处不被读错，再合成全片。必要时在中央 preset 加词组级同音替换，字幕仍保留原字。
- 字幕：以口播稿原文为准；ASR 只取词级时间，不直接采用 ASR 文字。若 TTS 用了同音替换（如“花辣子模”），字幕要回填原字“花剌子模”。
- 音频登记：单条通讲可登记到第 1 帧；若按幕配音，则每幕单独合成并用 `--frame-id N` 登记。`audio_meta.json` 的 `voices[]` 必须带数字 `frame`。

## 六、音频 / 音效

- 旁白只用 GPT-SoVITS dabao；**禁止** HyperFrames 内置 TTS（Kokoro / HeyGen / ElevenLabs / Gemini）。
- BGM / SFX 尚未选定；旧项目的 score / sfx 已删除。使用前逐项确认授权，再按 media-use 的 host 方式登记。没有授权曲目时，先出无 BGM 版本。
- 建议声音方向（仅方向，不是曲目）：低频鼓点 + 纸张摩擦 + 印章落桌；不要战争大片式铜管，避免把历史讲解做成预告片。

## 七、审稿门

1. 用户审 `口播稿.txt`：史实口径、语气、长度。
2. 审过后再做 20–30 秒专名试听；确认读音后才合成全片。
3. 合成后转写、登记 `audio_meta.json`，用实际音频回写分镜时码。
4. 进 HyperFrames composition，先出 15 秒画面测试（地图 + 印章 + 档案卡），再出全片。
5. 出片后按项目交付规则附 QA：时长、分辨率、帧率、黑帧、响度 / 峰值。
