# tushuo 技术路线与对标调研

核对日期：2026-10-16。星标数是当日 GitHub 页面显示值，会变化。此处比较适合数据驱动历史地图动效的可复用项目，不把完整白板应用计作底层框架。

| 路线 | 项目 | 星标 | 许可 | 与 tushuo 的关系 |
|---|---|---:|---|---|
| Canvas 2D 通用图形 | [Fabric.js](https://github.com/fabricjs/fabric.js) | 31.5k | MIT | 交互变换、SVG/JSON 导入导出成熟；需自建视频时间轴与逐帧渲染。 |
| Canvas 2D 视频动效 | [Motion Canvas](https://github.com/motion-canvas/motion-canvas) | 19.4k | MIT | 为讲解型矢量动效及旁白同步设计，支持 FFmpeg 视频导出；需定制地图、军队、战术标注组件。 |
| Canvas 2D 场景图 | [Konva](https://github.com/konvajs/konva) | 14.9k | MIT | 分层场景和交互适合未来编辑器；当前样片仍需自建时间轴和导出。 |
| React 组件视频 | [Remotion](https://github.com/remotion-dev/remotion) | 64.4k | 专有许可 | React 组件、音频、字幕与帧级视频渲染完整；公司使用须核对许可条件。 |
| React + Canvas 2D | [react-konva](https://github.com/konvajs/react-konva) | 6.4k | MIT | 若后续需要 React 可视化编辑台，可复用 Konva 的场景图。 |

首条样片选 **原生 Canvas 2D + 可寻址时间轴 + Playwright 逐帧导出 + FFmpeg 合成**。这是在 Canvas 2D 路线上自建专用场景，而不是使用高星框架的全部能力：地图纹理、粒子、船队、标注都需要逐帧精确定位，当前没有拖拽编辑需求。选型先接受这部分工程量，以换取脚本/数据直接驱动和无人值守渲染。Motion Canvas 的讲解动画 API 仍作为后续组件实现参考，但其官方导出主要由浏览器编辑器触发；[无头渲染需求讨论](https://github.com/motion-canvas/motion-canvas/issues/1218)至今仍开放，长期“输入主题自动成片”需要我们另建自动化。Fabric.js 与 Konva 适合后续编辑器，不作为首条样片的逐帧底层。Remotion 的 React 组件与渲染 CLI 更完整，但须先核对公司使用许可。

许可依据：[Remotion 许可问答](https://www.remotion.dev/docs/license/faq) 说明个人或总人数不超过 3 人的组织可用免费许可，其他组织的使用情形可能需要 Company License；[Motion Canvas 视频导出说明](https://motioncanvas.io/docs/rendering/video/) 列出 FFmpeg 导出；[Remotion 渲染说明](https://www.remotion.dev/docs/render) 列出 Studio、CLI 与服务端渲染方式。

## 本机条件

- Intel Core 5 220H，16 逻辑处理器；内存约 32 GB；Intel Graphics 核显。
- 本机 FFmpeg 可用 Intel Quick Sync 编码 1080p H.264。真实地图场景首轮 1860 帧约 10 分 22 秒，约 3.0 fps；瓶颈主要是 1080p 浏览器截图、PNG 传输与逐帧合成。
- alannew 既有 3D 全片在此机上约 5–6.5 fps，来自知识库 `training/SKILL-e6ff50.md`。tushuo 首版的逐帧导出尚未比其更快，后续需要优化截图/编码管线；画面设计和自动化仍可继续沿用此路线。

## 两段对标视频

- “地图知天下·官渡之战”：207.54 秒、1920×1080、30 fps。地图上有大量地名、色块、军旗/人物单位，穿插 3D 战场镜头。抽帧见 `research/reference-1-01.jpg`。tushuo 要重点改善缩放时的标签密度和关键部队的视线层级。
- “历史图说·襄阳”：292.36 秒、1920×1080、30 fps。以地形纹理、政权色块、河网、路线和年代信息讲述，地图占画面主体。抽帧见 `research/reference-2-01.jpg`。tushuo 要将地形质感与更明确的兵力、路线、时间关系结合。

两段视频仅作视觉与节奏参考，原文件保留在项目根目录，不直接复用其画面或音频。
