# 资产来源与许可

记录日期：2026-10-20（项目转为 HyperFrames 主导后的整理版）。

| 资产 | 来源与用途 |
|---|---|
| `content/` | 事实底稿、分镜与口播稿，项目内编写；史料来源见各 `事实底稿.md`。 |
| `三国人物/` | 项目方提供的 64 张人物原图，用作历史人物视觉。 |
| `assets/commanders/` | 由 `三国人物/` 原图裁切/统一生成的主帅卡；无影视剧照拼接。 |
| `assets/maps/` | 历史地形与地图示意素材，供 HyperFrames 画面复用；岸线、营寨、距离是可读性重建，不是精确古地理数据。 |
| `assets/brand/xualan.jpg` | 项目方提供的品牌头像。 |
| 旁白 | 本机 GPT-SoVITS **dabao** 预设（v2 底模 + 私人参考音频的零样本克隆）；参考音频与试听样音不随仓库分发。 |
| 配乐/音效 | 使用前逐一确认授权；旧 Canvas 管线的 `score.json` / `sfx-track.json` 已删除。 |
| `films/mongol-west-1/assets/voice/narration.fixed.mp3` | 本片旁白，dabao 生成；含私人音色，不随公开仓库分发。 |
| `output/mongol-west-1/bed.wav` | 本片原创音床与音效，用 Python/NumPy 合成（低频鼓点、纸张、印章、银液声），无外部采样；可随片分发。 |
| `films/mongol-west-1/vendor/fonts/` | Noto Serif SC / Noto Sans SC 可变字体，取自本机 Windows 字体目录；SIL Open Font License 1.1，发布前复核字体版权页。 |
| `films/mongol-west-1/vendor/gsap.min.js` | GSAP 3.15.0；按 GreenSock 标准许可使用，发布前复核许可范围。 |
| `films/mongol-west-1` 地图 | 手绘示意地图；只参照通行地理轮廓，不复制现代政治边界或受版权保护的地图作品。 |
| 对标视频 | 仅做构图、信息层级与节奏研究，不复用帧、音频、字幕或图形素材。 |

公开发布前需要逐项确认美术、地图、字体、音乐和音效的授权范围。
